# DecodeLabs Data Analytics Internship Projects

This repository documents my practical work completed during the
**DecodeLabs Data Analytics Internship**, using an e-commerce order
dataset to demonstrate the progression from raw data preparation to
exploratory analysis and business-focused visualization. The final Excel
workbook consolidates my work for **Project 1 (Data Cleaning and
Preparation), Project 2 (Exploratory Data Analysis), and Project 4 (Data
Visualization)**.

## Project Overview

The internship projects were designed to develop practical data
analytics skills by working through different stages of the analytics
process. I used Excel to clean and prepare the dataset, investigate
patterns and outliers, summarize business performance, and communicate
the resulting insights through charts and dashboard-style visuals.

### Project 1 --- Data Cleaning and Preparation

The first project focused on preparing the raw dataset for analysis. I
reviewed the data for issues such as missing values, unwanted spaces or
characters, duplicate or recurring records, inconsistent formatting, and
incorrect data types, while documenting the changes in an **Action
Log**.

**Main output:** a cleaned and analysis-ready dataset containing **1,200
order records**.

### Project 2 --- Exploratory Data Analysis

The second project focused on understanding the cleaned dataset through
descriptive statistics and exploratory analysis. I calculated summary
measures, investigated the distribution of order values and potential
outliers, and used PivotTables to explore trends across products, order
statuses, customer acquisition channels, promotional offers, payment
methods, and time periods.

**Main output:** descriptive statistics, outlier analysis, PivotTables,
and summarized business observations.

### Project 4 --- Data Visualization

The fourth project focused on transforming the analytical findings into
clear and stakeholder-friendly visuals. I created charts to communicate
order-value trends, product performance, order outcomes, acquisition
channels, promotional offer usage, payment methods, and other important
patterns identified during the analysis.

**Main output:** a collection of Excel visualizations and a
dashboard-style presentation of the key findings.

## Key Dataset Summary

-   **1,200 orders**
-   **3,535 units ordered**
-   **\$1,264,761.96 total recorded order value**
-   **\$1,053.97 average order value**
-   Analysis covered product performance, order outcomes, acquisition
    channels, promotional offers, payment methods, time trends, and
    outliers.

> **Note:** Total order value represents the value recorded in the
> dataset and should not automatically be interpreted as realized
> revenue because the dataset also contains cancelled and returned
> orders.
